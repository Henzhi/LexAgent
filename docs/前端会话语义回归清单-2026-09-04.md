## 场景 1：生成中切换到另一个对话 → 后台跑完并落库（D-0904-1）

| 步骤 | 操作 | 预期 |
| :--- | :--- | :--- |
| 1.1 | 发起一个耗时较长的提问（如"起草一份房屋租赁合同"触发 B 类确认后执行，或长问题） | 回答流式输出中 |
| 1.2 | 回答生成到一半时，点侧边栏切换到另一个对话 | **不打断生成**：无"已停止生成"字样；切到的会话正常显示 |
| 1.3 | 等 10~30 秒后切回原对话 | 看到完整答案（含 sources / 思考过程），不是空白 |

| 1.5 | 刷新页面再看该会话 | 答案仍在（已落库），且**只有一条** assistant 回答（无重复落库） |

| :--- | :--- | :--- |
| 4.1 | 生成中点「停止」 | 立即停止；已生成部分保留并落库；sessionStorage 的 `lawrag_pending_stream` 被清除（DevTools → Application 查看） |
