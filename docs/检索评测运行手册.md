## 3. 命令速查（都在仓库根目录执行）

```bash
# 基线（vector PROD：pgvector+rerank+adjacent+hybrid 全链）

TAVILY_API_KEY= uv run python evaluation/scripts/eval_retrieval.py \
  --queries evaluation/data/eval_queries_colloq_llm.json --tag colloq148

TAVILY_API_KEY= uv run python evaluation/scripts/eval_retrieval.py --mode bm25 \

# 法名推断离线评测（质心法，秒级）
TAVILY_API_KEY= uv run python evaluation/scripts/eval_law_name_inference.py \
  --mode centroid --tag centroid
```

**开关型实验**（改环境变量，不动代码/配置文件）：

```bash
# 粗排召回池扩容探针（reranker 算 40 对/查询）
RERANK_RECALL_K=40 TAVILY_API_KEY= uv run python evaluation/scripts/eval_retrieval.py \
  --queries evaluation/data/eval_queries_colloq_llm.json --tag colloq148_recall40

# LLM 改写双路融合（无法名查询 +1 次 DeepSeek 改写 + 双路检索）
REWRITE_FUSION_ENABLED=true TAVILY_API_KEY= uv run python evaluation/scripts/eval_retrieval.py \
  --queries evaluation/data/eval_queries_colloq_llm.json --tag colloq148_rw

# 叠加（recall40 + 融合同时开）
RERANK_RECALL_K=40 REWRITE_FUSION_ENABLED=true TAVILY_API_KEY= \
  uv run python evaluation/scripts/eval_retrieval.py \
  --queries evaluation/data/eval_queries_colloq_llm.json --tag colloq148_recall40_rw
```

⚠️ **两个铁律**：
- `TAVILY_API_KEY=` **必须清空**（否则 .env 的真 Key 让 web_search 类用例假失败/真调用）；
- `--tag` **必须唯一**（报告文件按 tag 落盘，重名互相覆盖——已两次踩坑）。

输出被 `tail` 缓冲时日志 0 字节**不代表挂了**，等完成通知。

## 5. 报告在哪、怎么看

- 文本报告：`evaluation/data/lexeval/results/retrieval_<mode>_<tag>.txt`
- 逐条明细：同名 `.jsonl`（id/query/hit@5/mrr/top_citation——逐条 diff 用这个）
- 法名推断：`law_name_inference_<tag>.txt/.jsonl`

**看报告的顺序**：先 Hit@5 / MRR（生产进 prompt 的是前 5~8 条，这两个是
关键指标；Hit@10 高只说明长尾召回好）→ 再开 jsonl 与基线逐条对比，
统计"丢失/新增"清单，丢的每条都要能解释。

## 6. 跑完之后做什么（决策树）

### 6.1 recall40 探针（已命中：73→79.7%，+6.7）

```text
✅ 已验证 → 转正流程：
1. .env 与 src/config.py 的 RERANK_RECALL_K 默认值 15→40（带注释）
2. 重跑 multi100 确认 92% 不回归
3. 提交（fix: 粗排召回池扩容…）
```

### 6.2 改写融合（单开：Hit@1 +4.8 / Hit@5 持平 / multi100 91% 无回归）

判读规则：
- **叠加实验出分后**对比三行：基线 73 / recall40 79.7 / 叠加 X
- X ≥ 82（超 recall40 增益 2 点以上）→ 融合转正（默认开关改 true，验收延迟预算）
- X ≈ 79~81（与 recall40 基本重合）→ 融合被 recall 池覆盖，保持默认关，
  代码留作 LLM 信号接入点
- X < 79 → 叠加有干扰，查 jsonl 逐条 diff 归因后再定

### 6.3 任何"负结果"

照 B2 加权 NO-GO 的先例：回退开关、保留代码与实验链、归因写入报告、
教训入 `.workbuddy` 记忆与常见错误清单。负结果同样入库。
